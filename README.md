# ActivityLifeCyclesKotlin

A simple Android application demonstrating the **Activity Lifecycle** in Kotlin.
This project helps understand how Android activities behave during different states like creation, start, pause, resume, stop, and destruction.

---

## 🚀 Features

* Demonstrates all major Activity lifecycle methods:

  * `onCreate()`
  * `onStart()`
  * `onResume()`
  * `onPause()`
  * `onStop()`
  * `onDestroy()`
* Logs lifecycle events clearly for learning purposes
* Simple and beginner-friendly UI
* Built using Kotlin

---

## 🛠️ Tech Stack

* **Language:** Kotlin
* **IDE:** Android Studio
* **Platform:** Android SDK

---

## 📱 How It Works

The app tracks and displays/logs lifecycle method calls as you interact with it.

Try these actions to see lifecycle changes:

* Open the app → `onCreate()`, `onStart()`, `onResume()`
* Press Home → `onPause()`, `onStop()`
* Return to app → `onRestart()`, `onStart()`, `onResume()`
* Close app → `onPause()`, `onStop()`, `onDestroy()`
